## Getting Started

Fetch the codebase locally:

```bash
git clone https://github.com/daniel-zimmer1/battery-bot-site-2026.git
cd REPO
```

To run the site without a server, launch the entry HTML document in your browser. For systems with an `index.html` file, execute:

```bash
open index.html
```

On Windows environments, double-click `index.html` or launch via PowerShell:

```powershell
start index.html
```

Alternatively, load the project folder into your preferred local HTTP server.
